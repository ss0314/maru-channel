maru-channel

YouTube への投稿を予約する個人用ツール

maru-channel は、運営者が自分の YouTube チャンネルに、編集したショート動画をアップロードし、公開日時を予約するためのツールです。運営者のパソコンの上だけで動き、ほかの人には提供していません。

使う機能

  • YouTube Data API（YouTube API サービス）で、動画をアップロードし、公開日時を設定します
  • 投稿先のチャンネル名と、アップロードした動画の状態を読み取ります

プライバシーポリシー ・ YouTube 利用規約

About

maru-channel is a personal tool that uploads edited short videos to the operator's own YouTube channel and schedules their publication. It runs only on the operator's computer and is not offered to anyone else.

It uses the YouTube Data API (YouTube API Services) to upload videos, set their publish time, and read the channel name and the status of uploaded videos.
