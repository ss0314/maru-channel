maru-channel

プライバシーポリシー

制定日: 2026年11月3日

maru-channel（以下「本ツール」）が扱う情報について説明します。

YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。

アクセスする情報

Google アカウントで許可された範囲で、次の情報にアクセスします。

  • 投稿先チャンネルの情報（チャンネル名、チャンネル ID、ハンドル）
  • 本ツールでアップロードした動画の情報（タイトル、説明文、公開設定、公開予定日時、処理の状況）

情報の使い方

動画のアップロードと公開日時の設定、およびその結果の確認だけに使います。広告や分析など、ほかの目的には使いません。

情報の保存

  • 認証情報（OAuth トークン）は、運営者のパソコンの macOS キーチェーンにだけ保存します
  • 投稿の記録（動画 ID、タイトル、公開日時）は、運営者のパソコン内のファイルに保存します
  • 外部のサーバーには保存しません

第三者への提供

取得した情報を、第三者に提供したり販売したりしません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる、Google API から受け取った情報の利用とほかのアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセス許可の取り消し

本ツールへのアクセス許可は、Google アカウントのサードパーティ製のアプリとサービスから、いつでも取り消せます。取り消すと、本ツールは YouTube にアクセスできなくなります。

お問い合わせ

Privacy Policy (English)

Effective date: November 3, 2026

maru-channel (the "Tool") uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. For how Google handles information, see the Google Privacy Policy.

Information accessed. Within the scopes granted through the Google account, the Tool accesses the destination channel's name, ID and handle, and the title, description, privacy status, scheduled publish time and processing status of videos uploaded with the Tool.

Use. The information is used only to upload videos, set their publish time, and check the results. It is not used for advertising, analytics or any other purpose.

Storage. OAuth tokens are stored only in the macOS Keychain on the operator's computer. Upload records (video ID, title, publish time) are stored in a file on the same computer. Nothing is stored on external servers.

Sharing. The Tool does not share or sell any information to third parties.

The Tool's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. You can revoke the Tool's access at any time from Third-party apps & services in your Google account.

Contact. Please use GitHub Issues.
